# Data

`vehicles.csv` is the dataset supplied with UC Berkeley Module 11 Practical Application II (426,880 rows, 18 columns). The source is a sample of used-car advertisements. **Price is asking price, not a recorded sale.**

The CSV is bundled in the downloadable submission ZIP for reproducibility. If your GitHub repository rejects or discourages large files, exclude `vehicles.csv` from GitHub and download it from the original course starter package, placing it at `data/vehicles.csv`.
