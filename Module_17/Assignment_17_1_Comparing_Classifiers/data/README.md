# Data provenance

All three files in this directory were extracted unchanged from the instructor-provided `module17_starter.zip`. The primary analysis uses `bank-additional-full.csv` (41,188 records); the 4,119-record `bank-additional.csv` is retained for reference but not used in the primary model comparison. The dataset uses semicolon delimiters. See `bank-additional-names.txt` for variable descriptions and the recommended citation.
